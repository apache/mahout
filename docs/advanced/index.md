# PQC Guides

In-depth material on parameterized quantum circuits (PQCs) in Qumat. Start with the [Parameterized Circuits](../qumat/parameterized-circuits) page for the basics of rotation gates and parameter binding, then continue here.

- [PQC Developer's Guide](./pqc): the theory, design, and applications of PQCs, written for developers implementing them from scratch
- [Qumat PQC Gap Analysis](./gap-analysis): what the Qumat codebase needs for a minimally viable and then a feature-complete PQC implementation
- [Quantum Kernel Methods](./quantum-kernels): design notes for quantum (fidelity) kernels in Qumat: feature maps, overlap estimation, and how the kernel matrix feeds classical learners
